1. 도넛픽이란?

도넛픽은 서버 없이 GitHub만으로 돌아가는 이미지 호스팅 서비스입니다. 이미지를 드래그해서 올리면 어디서든 쓸 수 있는 영구 이미지 주소가 만들어집니다.

  • 💰 완전 무료 — 서버비, 도메인비 0원
  • 🖱️ 드래그&드롭 업로드 — 큰 사진은 자동으로 리사이즈
  • 🔗 영구 주소 제공 — https://아이디.github.io/img/파일명
  • 📸 공유 갤러리 — 방문자 제보 + 관리자 승인제
  • 🗂️ 모든 사진이 git으로 관리 — 실수로 지워도 복구 가능
↑ 목차로

2. 동작 원리

도넛픽은 GitHub의 세 가지 기능을 조합해서 만들어졌습니다.

기능역할
GitHub Pages저장소의 HTML/CSS/JS와 이미지를 웹사이트로 공개 (호스팅 담당)
GitHub API브라우저에서 직접 저장소에 이미지를 커밋/삭제 (업로드 담당)
GitHub Actions방문자 제보를 승인하면 자동으로 갤러리에 추가 (자동화 로봇)

업로드 흐름은 이렇습니다:

  1. 브라우저가 이미지를 읽어 필요하면 리사이즈 (긴 변 1600px)
  2. GitHub API로 저장소의 img/ 폴더에 커밋
  3. 1~2분 안에 GitHub Pages가 새 이미지를 웹에 공개
  4. 갤러리는 API로 img/ 폴더 목록을 읽어 표시

3. 설치하기

내 계정으로 도넛픽을 새로 설치하는 과정입니다. 이미 운영 중인 사이트를 쓰고 있다면 이 장은 건너뛰어도 됩니다.

3-1. 준비물

  • GitHub 계정 (github.com/signup에서 무료 가입)
  • 도넛픽 소스 코드 (이 저장소를 복사)

3-2. 저장소 만들기

  1. GitHub 로그인 → 우측 상단 + → New repository
  2. 저장소 이름: 아이디.github.io (예: 아이디가 aisays면 aisays.github.io)
    💡 이름을 정확히 아이디.github.io로 지으면 대표 주소가 됩니다. 다른 이름을 쓰면 주소가 아이디.github.io/저장소이름이 돼요.
  3. 공개 범위: Public 선택
    ⚠️ 무료 계정은 Public 저장소만 GitHub Pages를 쓸 수 있습니다. 코드와 이미지가 모두 공개되니 민감한 정보는 절대 올리지 마세요.
  4. Create repository 클릭

3-3. 파일 올리기

방법 A — 웹에서 올리기 (git을 몰라도 OK):

  1. 저장소 페이지에서 uploading an existing file 링크 클릭
  2. 도넛픽 파일 전체(index.html, manual.html, css/, js/, .github/ 폴더 등)를 드래그
  3. Commit changes 클릭

방법 B — git 명령어로 올리기:

git init
git add .
git commit -m "도넛픽 설치"
git branch -M main
git remote add origin https://github.com/아이디/아이디.github.io.git
git push -u origin main

3-4. 내 계정 정보로 바꾸기

js/app.js 파일 맨 위의 상수 두 개를 내 것으로 수정합니다:

const OWNER = "아이디";          // 내 GitHub 아이디
const REPO  = "아이디.github.io"; // 저장소 이름

index.html의 "사진 제보하기" 버튼 링크와 .github/ 폴더 안의 주소도 같은 방식으로 바꿔 주세요.

3-5. GitHub Pages 켜기

  1. 저장소 → Settings → 왼쪽 메뉴 Pages
  2. Source: Deploy from a branch / Branch: main, 폴더 / (root) → Save
  3. 1~2분 뒤 https://아이디.github.io 접속 → 사이트가 뜨면 설치 완료! 🎉

3-6. 공유 갤러리용 라벨 만들기

저장소 → Issues → Labels → New label로 두 개를 만듭니다:

  • photo-submission — 방문자 제보 표시용
  • approved — 붙이면 로봇이 갤러리에 자동 추가

4. 관리자 설정 (업로드 토큰)

사이트에서 직접 업로드하려면 GitHub 토큰(저장소 쓰기 열쇠)을 브라우저에 등록해야 합니다.

4-1. 토큰 발급

  1. GitHub → 우측 상단 프로필 → Settings
  2. 왼쪽 맨 아래 Developer settings
  3. Personal access tokens → Fine-grained tokens → Generate new token
  4. 설정:
    • Token name: donutpic-upload (아무거나)
    • Expiration: 90일 이상 원하는 만큼
    • Repository access: Only select repositories → 내 저장소만 선택
    • Permissions → Repository permissions → Contents: Read and write
  5. Generate token → github_pat_...로 시작하는 토큰 복사
    ⚠️ 이 화면을 벗어나면 토큰을 다시 볼 수 없어요. 바로 복사하세요!

4-2. 사이트에 등록

  1. 내 사이트 접속 → 우측 상단 🔑 관리자 버튼
  2. 토큰 붙여넣기 → 저장 → "✅ 저장 완료" 확인
💡 토큰은 등록한 브라우저에만 저장됩니다(localStorage). 폰에서도 쓰려면 폰 브라우저에서 한 번 더 등록하세요. 공용 PC에는 등록하지 마세요!

4-3. 토큰 관리

  • 만료됐을 때: 같은 방법으로 새로 발급 → 다시 등록
  • 유출이 의심될 때: GitHub → Developer settings에서 해당 토큰 Revoke(폐기) → 새로 발급
  • 브라우저에서 지우기: 🔑 관리자 → 토큰 삭제

5. 기본 사용법

5-1. 이미지 업로드

  1. 메인 화면의 점선 상자에 이미지를 드래그하거나 클릭해서 선택 (여러 장 가능)
  2. 업로드가 끝나면 갤러리에 바로 나타남
  • 지원 형식: JPG, PNG, GIF, WebP
  • 긴 변이 1600px보다 큰 사진은 자동으로 줄여서 올림 (용량 절약)
  • 원본 화질이 필요하면 "원본 크기 그대로 올리기" 체크

5-2. 이미지 주소 복사 (호스팅 기능)

  1. 갤러리에서 사진 클릭 → 크게 보기
  2. 🔗 이미지 주소 복사: https://아이디.github.io/img/파일명 형태의 영구 주소 복사
  3. 📝 마크다운 복사: ![파일명](주소) 형태로 복사 — GitHub README나 블로그에 바로 붙여넣기
💡 방금 올린 사진의 주소는 GitHub Pages 반영까지 1분 정도 걸릴 수 있어요. 갤러리에는 바로 보입니다.

5-3. 방문자가 볼 수 있는 것

  • 갤러리 구경, 크게 보기, 주소 복사 — 누구나 가능
  • 직접 업로드/삭제 — 토큰 등록한 관리자만
  • 사진 제보 — GitHub 계정만 있으면 누구나 (다음 장 참고)

6. 공유 갤러리 운영

방문자가 사진을 제보하고 관리자가 승인하면 갤러리에 올라가는 승인제 시스템입니다.

6-1. 방문자 입장: 사진 제보하기

  1. 사이트에서 📸 사진 제보하기 버튼 클릭 (GitHub 로그인 필요)
  2. 열리는 양식의 "사진" 칸에 이미지를 드래그 (여러 장 가능)
  3. 이미지 업로드가 끝날 때까지 잠시 기다렸다가 Submit new issue 클릭

6-2. 관리자 입장: 승인/거절

  1. 제보가 오면 GitHub 알림이 옴 → 저장소 Issues 탭에서 확인
  2. 승인: 이슈 오른쪽 Labels에서 approved 클릭 → 끝!
    • 로봇이 사진을 내려받아 갤러리에 추가
    • 제보자에게 감사 댓글을 달고 이슈를 자동으로 닫음 (1~2분)
  3. 거절: 라벨 없이 그냥 Close issue — 아무 일도 일어나지 않음
⚠️ approved 라벨은 신중하게! 붙이는 순간 그 이슈의 모든 이미지가 갤러리에 공개됩니다.

7. 이미지 삭제와 관리

7-1. 삭제 방법 3가지

방법절차이럴 때
사이트에서사진 클릭 → 🗑️ 삭제 (토큰 등록된 브라우저만)한두 장 지울 때 (제일 쉬움)
GitHub 웹저장소 → img → 파일 → ... → Delete file폰이나 다른 PC에서
git 명령어파일 삭제 후 git add -A && git commit && git push여러 장 한꺼번에 정리

7-2. 알아둘 것: git 히스토리

  • 삭제해도 과거 커밋 기록에는 남아 있습니다 → 실수로 지워도 복구 가능 (장점)
  • 반대로, 절대 공개되면 안 되는 사진은 삭제만으로는 부족 → 히스토리 정리 작업 필요
  • 히스토리에 쌓인 용량은 삭제해도 줄지 않음 → 저장소가 1GB에 가까워지면 정리 필요

8. 문제 해결 (FAQ)

Q. 업로드 버튼을 눌러도 "토큰을 등록해 주세요"라고 나와요

업로드는 관리자 전용입니다. 4장을 따라 토큰을 발급받아 등록하세요. 방문자라면 📸 사진 제보하기를 이용하면 됩니다.

Q. 업로드했는데 "이미지 주소"로 접속하면 404가 떠요

GitHub Pages 반영에 1~2분 걸립니다. 잠시 후 새로고침 해보세요. 갤러리에 사진이 보인다면 업로드 자체는 성공한 거예요.

Q. 토큰을 저장했는데 업로드가 실패해요

  • 토큰 권한이 Contents: Read and write인지 확인
  • Repository access에 이 저장소가 선택되어 있는지 확인
  • 토큰이 만료되지 않았는지 확인 (만료 시 새로 발급)

Q. 승인 라벨을 붙였는데 사진이 안 올라와요

  • 저장소 Actions 탭에서 "사진 승인" 워크플로가 실행됐는지, 에러가 없는지 확인
  • 이슈에 photo-submission 라벨이 같이 붙어 있어야 로봇이 동작합니다
  • 제보자가 이미지를 첨부하지 않고 글만 썼다면 추가되지 않습니다

Q. 갤러리가 "목록을 불러오지 못했어요"라고 나와요

GitHub API 조회 제한(로그인 없이 시간당 60회/IP)에 걸렸을 수 있습니다. 잠시 후 새로고침 하면 돌아옵니다. 관리자는 토큰이 등록돼 있으면 제한이 훨씬 넉넉해요(시간당 5,000회).

Q. 폰에서도 업로드하고 싶어요

폰 브라우저로 사이트에 접속해서 🔑 관리자 → 같은 토큰을 등록하면 폰 사진을 바로 올릴 수 있습니다.

9. 한계와 주의사항

항목내용
파일 크기1장 최대 100MB (50MB부터 경고) — 자동 리사이즈를 켜두면 걱정 없음
저장소 용량전체 1GB 이내 권장
트래픽월 100GB 권장선 — 개인 갤러리는 넘을 일 거의 없음
용도 제한사이트에 쓰는 이미지는 OK. 순수 파일 창고/대용량 백업 용도는 GitHub 약관 위반
공개 범위모든 이미지는 전 세계에 공개됨 — 개인정보가 담긴 사진 금지
동영상부적합 — YouTube 등 전문 서비스 이용
⚠️ 토큰은 비밀번호처럼! 코드에 붙여넣거나 다른 사람에게 보내지 마세요. 토큰은 브라우저에만 저장되어야 합니다.
