🔑 관리자 설정

업로드하려면 GitHub 토큰이 필요해요. 토큰은 이 브라우저에만 저장됩니다.

토큰 만드는 법: GitHub → Settings → Developer settings → Fine-grained tokens → Generate new token → Repository access에서 aisays.github.io만 선택 → Permissions에서 Contents: Read and write → 생성 후 복사
